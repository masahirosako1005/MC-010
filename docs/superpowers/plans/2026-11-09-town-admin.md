# 町側管理画面 Implementation Plan

> **For agentic workers:** executing-plansで現在のセッション内に実装する。ユーザーが共有状況以外の実装を指示済み。AGENTS.mdによりテスト・レビューは未実施とし、ビルド・migration・3001番への反映だけを行う。

**Goal:** 町側アカウントで概況、スポット管理、パンフレット登録状況を開く。

**Architecture:** users.account_roleを追加しsourceとは独立させる。管理APIを/api/adminに分離し、毎リクエストDBの役割から認可する。既存利用者の編集、訪問履歴、写真を保持する。

**Tech Stack:** TypeScript / React SPA / Node.js 26 / PostgreSQL。追加外部サービス・依存なし。

**Spec:** docs/spec.mdの町側管理画面、前回調査および2026-11-09の実装指示。

## 制約と判断

- 共有イベント、共有済み状態、公開URLは保留。
- ローカル専用town@example.test / 1111を追加。自己登録・メールによる自動昇格なし。
- 利用者一覧は匿名ID、出所、履歴数、作成状態と日時だけ。個人コメント・写真・アンケート本文は管理APIに含めない。
- スポットは削除せず公開停止。既存冊子は保持し、新規候補から除外する。名称等の変更は既存冊子にも反映。使用中カテゴリに必要なタグ削除は拒否。
- 新規スポットは既存冊子を次回再生成すると候補へ追加。全利用者の編集を一括変更しない。
- 管理変更はtransaction、revision、監査ログ。seedは管理編集を上書きしない。
- 管理UIは既存配色、44px操作、モバイル対応、ラベル・フォーカス・再試行・未保存警告。
- 作業は現在の配信用workspaceで行う。テスト・独立レビューはユーザー規則に従い実行しない。
