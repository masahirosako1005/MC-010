# スタンプラリーデモ入口 Implementation Plan

> 実装は writing-plans / executing-plans に沿って現在の作業フォルダーで行う。ユーザー指定によりテスト・独立レビューは実行しない。

**Goal:** 提供されたホーム画面画像内のメインビジュアルの左下に「旅のしおりをつくる」を重ね、スマホ枠付きのモバイル版へ移動するデモページを追加する。

**Architecture:** `/demo/rally` をReactの既存パス分岐へ追加する。提供PNGを背景として同梱し、実際の操作はモバイル版 `/demo/mobile` への通常リンクで行う。

**Tech Stack:** 既存のTypeScript、React、CSS、lucide-react。追加依存なし。

**Spec:** `docs/spec.md` と `docs/design.md` の「スタンプラリーからのデモ入口」。

## 制約と方針

- 既存の未コミット変更を保持し、DB・API・既存スマホデモの経路を変更しない。
- 画像の縦横比を保ち、画面の幅と高さに収める。ボタンは画像内のメインビジュアル左下へ相対配置する。
- ボタンは文字ラベル付きリンク、44px以上の操作領域、キーボードフォーカスを持つ。
- 画面全体をHTMLで再作成する案は採用しない。提供画像をそのまま表示する方法が今回のデモ目的に合うため。
