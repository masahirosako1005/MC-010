## 調査中に修正した不具合

**再生成409の回復導線。** 報告された409のレスポンス本文は未取得のため、同一原因と断定しない。別画面で保存した後の `revision_conflict` を専用DBで再現した。修正前は回復ボタンがなく失敗、修正後は条件画面上部へエラーを表示し、最新情報の明示取込→再作成が成功。手元と別画面の別々のコメントが両方残ることをPC/スマホで確認した。同一項目を双方で変更した場合は手元の変更を優先する。409を成功扱いにしたり無条件で上書きしたりしない。

**隠しフォルダー配下の共有ページ。** 固定コピーの `.local` 配下から `/share/...` を開くと、絶対ファイル名のdotfile判定で `web_not_built` 503となった。固定の `index.html` を指定した配信rootから返す形へ変更。dotfiles拒否は維持し、共有URLの直接表示をE2Eで確認した。

旧タイトル・旧CTA・空コメントの代替表示・共有保留を前提としていたテストは、ユーザーが指示した現在の仕様に合わせた。
