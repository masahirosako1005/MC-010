# 公開URLのスマートフォン表示

**目的:** 公開ページを既存のスマホ枠で表示し、スマホ枠からコピーした共有URLで同じ表示を再現する。

**方式:** 既存の `/share/<token>` に `?view=mobile` を付けて外枠を表示する。内側は固定の `/demo/mobile/share/<token>` で同じ読み取り専用ページを使用する。トークンは既存の64文字の小文字16進数のみを受け付け、任意URLをiframeへ渡す設定は設けない。API・DB契約は変更しない。

- [x] `src/shared/mobile-demo.ts` に公開ページのトークン抽出と埋め込み専用パス判定を集約する。
- [x] `main.tsx`・`MobileDemo.tsx`・`SharedPage.tsx` で公開ページのスマホ枠、表示切替、枠内のログイン／編集への導線を接続する。
- [x] `SharePanel.tsx` でスマホ枠からコピーするURLと手動コピーURLへ表示指定を付ける。既存の公開・コピー記録処理は維持する。
- [x] 埋め込み専用パスのみ同一originのフレームを許可し、仕様・デザイン・利用方法へ反映する。
- [x] Node 26と固定pnpmでビルドし、3001番のプロジェクトアプリだけをHiddenで再起動する。最小限のHTTP参照で配信状態を確認する。

ユーザーの開発ルールに従い、追加テスト・check・audit・E2E・独立レビューは実行しない。共有本文や実際の共有トークンを資料・ログへ転記しない。

実施結果: Node 26.13.0・pnpm 11.25.0でビルド成功。アプリをHiddenで再起動し、health・公開ページのスマホ表示URL・埋め込みページの200を確認。画面目視とコピー操作は未実施。
