各ディレクトリのMarkdown・HTML・JSONは同じ監査の報告書、構造化データ、対象版の根拠として一組で保持する。資料整理を理由に監査結果を書き換えたり、未確認事項を解消済みに変更したりしない。HTMLを外部公開する場合もMarkdownと同じ配布範囲を適用する。

OS強制sandboxを必要とする正式Cloudflare full auditと、ソース監査・通常製品テストを区別する。[Cloudflare適用記録](../security-skill-review.md) の未完了状態は、ソース監査工程の完了によって変更しない。
