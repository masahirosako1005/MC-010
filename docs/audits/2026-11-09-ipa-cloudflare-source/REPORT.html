要確認: 候補と追加確認

NV-01 — ローカルデモ境界と認証強度

固定1111、HTTP cookie、local DB defaultはloopback限定に依存します。運用者がbind／firewall／proxy／共有端末／実データの有無を確認し、範囲を広げる場合は本人確認、TLS、Secure cookie、環境別secretへ変更します。

NV-02 — Sharp/native境界と現行lockのadvisory

入力上限はありますがnative decoderと現行pnpm lock advisoryは未確認です。credential-free隔離設定でadvisoryを確認し、必要なparser検証はOS強制sandboxとdummy画像だけで実施します。

NV-03 — 実配備header・DB権限・backup/recovery

source上のheader、loopback、復旧手順は確認済みです。非本番専用環境でeffective header、DB grants、backup ACL／暗号化／retention、復元後の画像参照をowner確認します。

NV-04 — aggregate資源上限

per-request上限はありますが、同時Sharp処理とCSV全体sizeの上限は未定義です。OS強制sandboxとdummy dataで小規模growthだけ測り、CPU／memory／time／concurrency limitを定めます。
