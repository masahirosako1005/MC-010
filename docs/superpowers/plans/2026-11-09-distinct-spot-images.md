# スポット画像の見分けやすさ

ユーザー依頼: 青背景の多いスポットを見分けられるようにする。

方針: 追加10件の既存画像使い回しをやめ、各場所に固有の水彩イラストを同梱する。料理、甘味、パン、工芸品、遊具、海遊び道具、足湯、歴史展示、土産、クラフト市を主役にし、青空や海が大きく占めない構図と、場面ごとに異なる暖色・紫・石色で区別する。既存7件、本人の写真、紙面のカテゴリ色は維持する。

- [x] 内蔵imagegenで専用10画像を作成し、生成物を確認してプロジェクト内へ保存する。
- [x] 同梱画像一覧、追加CSV、画像の説明資料を更新する。
- [x] 初回登録時の旧イメージ画像が残る追加スポットだけ、専用画像へ移行するコマンドを追加して実行する。町側で変更済みの画像や本人写真は上書きしない。
- [x] Node 26と固定pnpmでbuildする。3001番の対象アプリをHiddenで1回再起動し、最小HTTP参照を行う。
- [x] 実施結果と未実施のテスト・レビューを記録し、今回の変更だけをコミットする。

AGENTS.mdに従い追加テスト・独立レビューは実行しない。並行中の町側画面・共有計測・キャッシュ実装には触れない。画像生成は開発時のみで、アプリ実行時には外部APIを使用しない。
