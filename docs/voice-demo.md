# 音声付きデモ

ローカルのアプリが3001番で稼働し、Windowsの日本語音声とPlaywrightのブラウザが使える環境で、プロジェクトルートから次を実行します。

```powershell
.\.tools\node-v26.13.0-win-x64\node.exe scripts\voice-demo.mjs
```

スクリプトは `scripts/voice-demo-lines.json` の台本から `demo-audio` にWAVを生成し、表示状態と音声再生の終了を待って進みます。デモ利用者の初回作成または保存済みの状態に対応します。招待URLのコピーと閲覧を記録し、未使用のクーポンは使用確定します。終了後はブラウザを開いたままにし、手動でブラウザを閉じると終了します。デモアカウントの初期化は行いません。読み込みや操作の失敗時には中断します。

日本語音声の種類はWindowsにインストールされた最初の日本語音声を使用します。音量や出力先はWindows側で設定します。スクリプトの動作確認、音声再生、E2Eテストは未実施です。

各場面の音声開始前に説明対象を中央へスクロールし、オレンジ色の枠を短く表示します。音声再生中は画面を維持します。この追加の通し動作は未確認です。
