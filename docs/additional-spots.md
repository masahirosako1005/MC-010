## 登録・再投入

プロジェクトルートで、通常アプリと同じ `DATABASE_URL` を用いて実行する。

```powershell
pnpm run db:migrate
pnpm run data:import-additions
```

`data:import-additions` はこのCSVだけを読む専用コマンド。列名、10件であること、識別子、タグ、同行者、同梱画像参照、重複を検査してから、パラメータ化SQLと単一transactionで登録する。既存の同一外部IDはスキップするため、町側で編集した名称・タグ・画像・公開状態も上書きしない。登録結果は追加数、スキップ数、総スポット数、公開中のカテゴリ別候補数だけを出力する。

空DBへ元の7件をmigrationで用意した後、このコマンドを実行すると計17件となる。`db:seed` や元CSVの取り込みだけでは追加10件を登録しない。追加分は `fixture` であり、提供データの履歴を追加・変更しない。

保存済みのしおりの掲載・写真・コメントは登録時点で変更しない。ログイン済みの利用者は「旅の条件を変更」から再生成すると追加候補を取得する。新規しおりでは初回生成から対象になる。町側のスポット一覧は再読み込みすると反映する。
