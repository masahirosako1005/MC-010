2026-11-10、ユーザー依頼によりローカル稼働DBへ集計専用の架空利用者としおりを120組追加した。

再現用コマンド（Node 26、pnpm 11.25.0、対象DBの接続設定を使用）:

```powershell
pnpm run data:demo-analytics
```

通常のseedでは投入しない。専用名前空間は `fixture:admin-category-demo:v1:`。再実行は既存冊子を変更せず、未追加分だけを追加する。メールなしのためログイン用アカウントにはならない。既存利用者の編集や提供CSVは変更しない。
