# 公開URLのコピー数・アクセス数

ユーザーの追加指示に従い、既存の町側詳細画面へ両方の数値を表示する。コピーはClipboard成功後の確認イベント、アクセスは従来の本文表示イベント。既存のアクセス数を引き継ぎ、過去のコピー数は補完しない。

- [x] 008 migrationでコピー累計・最終日時と、操作UUIDによる再送除外のイベント表を追加する。
- [x] 作成者専用のコピー記録APIを追加。URL発行・キャンセル・手動コピーでは増やさず、コピー成功時に送信する。送信失敗時は同じUUIDで再試行し、未送信分の再記録を可能にする。
- [x] 共有状況の一覧・累計、作成詳細、スポット詳細の累計と日別推移へコピー数とアクセス数を表示する。スポットは現在掲載中のしおりの合計で、個別スポット閲覧と区別する。
- [x] 仕様・DB契約・操作説明を更新する。
- [x] Node 26でbuild、既存DBへ追加migration、対象アプリだけHidden再起動、最小HTTP参照で配信を確認する。

時間のかかる検証の保留を継続し、テスト・check・audit・独立レビュー・画面操作は実施しない。反映時点では作業ツリーへ保持し、後続のコミット依頼に従い管理詳細の追加とまとめてコミットする。別作業の監査レポートと画像変更の計画は対象外。
